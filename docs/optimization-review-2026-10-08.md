## 已实现的修正

| 原问题 | 1.7.0 实现 | 行为影响 |
| --- | --- | --- |
| 时间戳和冲突重命名设置未生效 | 批次保存读取捕获的设置，原名/时间戳命名实际接入 | 关闭冲突重命名时跳过冲突图片并提示；不覆盖旧文件 |
| 多图倒序、选区未替换 | 按输入顺序保存，一次编辑事务插入批次 | 粘贴替换选区一次；拖入在落点插入 |
| 异步插图与活动笔记可能不一致 | 捕获接收编辑器的笔记、设置与范围，映射期间文本变化 | 编辑器切换或关闭后不把链接写入另一篇文档；已保存图片按捕获笔记保留并提示 |
| 图片名与链接字符语义冲突 | 新文件名采用根参数文件中的兼容字符规则；读写端共用解析及编码 | 保留已有图片名称，支持编码字符、标题、说明与嵌套括号路径 |
| 断链修复猜中错误同名图 | 精确路径优先，缺失路径只接受全库唯一同名匹配 | 歧义图片不自动选首项；显式 Wiki 路径按路径解析 |
| 重复 Wiki 文字误替换首处 | 按每个出现位置转换，正文变更后要求重新扫描 | 可分别选择重复的同文字引用 |
| 当前笔记清理范围错误 | 按配置附件目录边界筛选，包括子目录；引用仍看全库 | 不按资产目录名模糊扩大清理范围 |
| 刚改链接后索引尚未刷新 | 扫描结合当前 Markdown/Wiki 正文与索引；清理前复核引用 | 降低索引延迟带来的误判，未增加后台服务 |
| 分享同名图覆盖及重复导出冲突 | 显式来源映射，唯一图片名、输出目录与 ZIP 名 | 同名不同来源独立打包，重复导出不覆盖，提示实际输出位置 |
| 系统目录选择与 Vault 写入不一致 | 删除系统目录选择器，明确库内相对父目录 | 空输入为库根；库外绝对路径及 `..` 段明确拒绝 |
| 分享遗漏 Wiki 图片、首次 ZIP 目录不存在 | 统一解析 Markdown/Wiki 图片，按层创建输出目录 | 来源笔记不变，代码示例及无法解析链接保持原文 |
| 重构全局去重让后续笔记漏图 | 每笔记独立来源映射及图片复制 | 每篇所选笔记得到自己的完整资产集 |
| 重构按目录前缀混入其他笔记资产 | 按选中笔记本身的引用分配目标 | 删除目录前缀猜测关联的旧路径 |
| 目标同名图被误当作正确图 | 冲突分配唯一名称，已在本篇正确目录的图复用 | 不改写到错误同名文件，重复整理正确资产不会新增副本 |
| 覆盖重构回收未选中笔记共享原图 | 所有来源图保留，单独审阅清理 | 重构删除原图数始终为 0；移除无关的无主图片阻塞 |
| 再次重构自身输出造成套娃 | 唯一输出目录，排除配置目录及编号输出 | 每次输出独立，预览与通知说明实际目录 |
| 跨编辑器保存命名竞争 | 共享保存队列，编辑器仍独立排队插入 | 不让分屏编辑器同时分配同一个目标文件名 |
| 库外引用中断操作、库根路径漏图 | 明确识别库内文件身份，库外无目标且保持原文 | 图片源使用实际解析目标；带目录 Wiki 不按裸文件名猜测 |
| 弹窗设置未持久化、选择状态变化 | 调用统一保存回调，执行时固定批次并禁用交互 | 导出选项可保存，取消全部选择后执行按钮禁用 |

## 参数与工具链

默认设置、重构输出目录及新图片文件名规则统一放在项目根 `settings.ts`；原 `src/settings.ts` 已移除，所有源码引用改到根参数文件。用户选项仍由 Obsidian 插件数据 API 保存，没有引入环境变量注入配置。

源码参数版本已更新为 1.7.0，构建工具 `esbuild` 更新并固定为 `0.28.2`，Obsidian SDK 固定为 `1.13.0`。移除已废弃且未用于现有 tag 发布工作流的 `standard-version` 及版本脚本。本轮 TypeScript 类型检查、生产构建及 `git diff --check` 通过。运行依赖审计 0 项；完整审计剩余 2 项 moderate，均由开发用 Obsidian SDK 的 moment 依赖引入。审计建议降级 SDK 到 0.14.5 与当前 API 不符，本轮不执行该降级。

## 资产与数据边界

本轮源码优化不批量改名已有图片。原地重构只复制图片并改写所选笔记链接，保留来源图；来源在当前正确 `.assets` 目录时复用。新副本数量由所选笔记实际可解析且需要复制的不同图片数决定。同一图片被多篇笔记共享时，各笔记拥有各自资产副本是预期结果。

来源图不会自动回收，实际清理需用户通过已有工具独立选择。无主图片工具的候选范围是 `.assets` 目录，来源位于其他目录时不在其清理范围内。本轮没有在真实用户库执行批量修复、转换、导出、重构或清理；真实笔记和图片的批量修改/删除量为 0。
