# Typorian Image 1.8.2 UI 统一交付记录

用户原始要求：“要改就所有UI统一风格”。本轮覆盖全部插件界面：图片检查、Wiki 格式转换、分享、附件重构、图片选择器、插件设置。

## 实施结果

- 所有窗口和设置页采用 typorian-ui 作用域；共享标题、主题颜色、控件、间距、列表卡片、路径、空状态、页脚和焦点样式。
- 范围/检查对象放在顶部，刷新和更多工具采用图标；全选及计数靠近结果；选中才显示相关批量动作。
- 分享、转换、重构的取消按钮采用低强调样式，主提交位于右侧；删除引用独立采用删除动作的悬停颜色。
- Wiki 转换显示原语法、缩略图、目标路径、来源定位及保留原因；全选、部分选择和提交数量同步更新。没有可转换项时不展示无效提交按钮。
- 分享把格式、目录和完成后打开目录集中为表单，显示当前笔记名称；原导出引擎保持。
- 附件重构以原生下拉框选择生成副本/原地整理；确认输入位于表单内。有效图片笔记优先排列，无图片项的计数和目标目录显示“—”，详细说明作为悬停提示。
- 图片选择器显示缩略图、名称和完整路径，保留原生模糊搜索与键盘选择。
- 设置按用途分区，当前行为和 Typora 配置指南默认折叠。
- 移除旧 orphan/wiki/share 样式和失效布局规则；旧 UI 计划标注为历史方案并链接当前计划。
