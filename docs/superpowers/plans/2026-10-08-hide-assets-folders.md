# 在文件列表中隐藏 Typora 图片目录

## 原始需求与约束

用户在 Obsidian 与 Typora 间共用笔记，以 `${notename}.assets` 保存图片，希望从 Obsidian 文件列表隐藏这些目录。用户先要求只读查看现状与计划，随后同意把功能加入 Typorian Image，并要求查看现有插件可能的优化项。

- 隐藏仅作用于文件列表，保留磁盘目录、链接、索引与现有图片处理行为。
- 采用设置开关，默认关闭；用户可启用，关闭或禁用插件后恢复显示。
- 匹配文件夹名称的 `.assets` 后缀，不写入用户的绝对路径。
- 沿用插件设置与中英文文案；不引入新依赖、轮询、全库扫描或内部 API 替换。
- 不新增测试、checksum 或隐式兜底；通过现有类型检查、构建和直接运行验收。
- 优化检查只读记录；其他图片处理行为的修正不混入本次隐藏功能。

## 验收标准

1. 开关启用后，已有 `.assets` 文件夹连同展开的子项隐藏，普通目录、笔记保留。
2. 新增或改名为 `.assets` 的目录由同一 CSS 规则自动匹配。
3. 开关关闭、插件卸载时目录恢复显示；重新加载插件后保留用户设置。
4. 笔记图片继续渲染；目录和图片仍存在；原有图片保存流程不变。
5. 无定时任务、目录扫描、额外依赖或文件移动。
