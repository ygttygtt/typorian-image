# Typorian Image 1.8.0 交付与验收记录

源码实现、本机安装与核心桌面操作验收完成。GitHub 提交合并状态待本轮收尾写入；未发布 tag 或正式 Release。

## 实际改动

- 保持单一插件，统一“图片检查”入口，下设失效图片引用、未引用图片两个方向。
- 当前笔记范围固定在打开窗口时的笔记，支持切换整个库；失效引用按出现位置操作，保留 Markdown 标题和 Wiki 别名/尺寸。
- 唯一同名候选可修复；多候选可预览选择；找不到时可手选库内图片或仅删除引用。
- 兼容名称修复生成副本并保留来源。少数历史路径只做同名候选支持，复用扫描事实，不增加额外追踪流程。
- 未引用候选来自附件目录，但引用判断覆盖整个库；实际目标和建议候选分开。清理明确选择后移入库回收站。
- Wiki 转换只做格式转换，尺寸引用保留；高级工具收进更多工具/命令，既有明确侧栏偏好保留。
- 分享显示真实输出路径、打包与未打包数量；重构保留引用语法并显示未打包数量。
- 删除旧 orphan / broken-link 独立模块与失效开关、更新中英文文档。
- AI 找图、联网检查来自脑暴中的范围外延伸，未纳入任何实现。

1. 阅读模式中的正常 Markdown 与带 |300 的 Wiki 图片渲染正常，不列为失效。
2. 重复失效 Wiki 两处：手选图片只修复第一处（修复1、影响笔记1、副本0），第二处仍存在；随后仅删除第二处（删除1、图片未删除）。
3. 特殊文件名图#?.svg：生成图__.svg兼容副本1张，原图保留、Markdown标题保留，修复后图片可见。
4. 代码示例未处理；库外引用1处排除于待修复计数，原文保留。
5. 未引用页：共享蓝色图片由另一篇笔记引用，因此没有进入列表；兼容修复后的来源和独立绿色图片显示为未引用。
6. 仅选择绿色图片移入回收站：实际1张、112字节，检查到 .trash/不用.svg；其他文件保留。
7. 从更多工具进入转换：当前笔记范围保持；普通Wiki转换1条，|300引用保留，转换窗口无删除清理动作。
